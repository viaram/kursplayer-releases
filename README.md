# KursPlayer – APK-Releases

Dieses Repo enthält nur die fertigen, signierten APKs des KursPlayers für Android-Tablets (ab Android 11) als [Releases](https://github.com/viaram/kursplayer-releases/releases). Der Quellcode ist privat.

## Installieren und aktualisieren mit Obtainium

1. [Obtainium](https://obtainium.imranr.dev) auf dem Tablet installieren.
2. In Obtainium „App hinzufügen“ antippen und als URL `https://github.com/viaram/kursplayer-releases` eintragen.
3. KursPlayer über Obtainium installieren. Neue Versionen meldet Obtainium dann von selbst.

Alle Versionen sind mit demselben Schlüssel signiert (Zertifikat SHA-256 `986d5023d5b08f524c3b2b876adc46e374029608a15bf55fb9180cf24865bc45`), sodass Updates Fortschritt und Kurse behalten.
